## Qualification boundary

CI builds all six platform/architecture artifacts once, checks the versioned
bundle on native Linux/macOS/Windows runners, and publishes those same bytes.
Windows amd64 CI remains supplementary to required Windows 11 ARM64 execution.
Changed product bytes require a new shared version and fresh affected platform
qualification; runner-only corrections retain their own revision and failures.

Mac acceptance uses the published darwin/arm64 binary and matching installer:
repeat installation, fresh-shell discovery, real onboarding, bounded live coding
and native Guardian allow/deny, preserve-uninstall, identical-byte reinstall,
saved-login reuse, and removal of owned test state. Ordinary authentication,
configuration, profiles and unrelated work must remain unchanged.

The explicit release sample is DeepSeek V4.1 Flash main with GLM 5.3 Flash Guardian
on the adapted CLI route. Each of the two lifecycle phases permits 12 upstream
requests (24 total), 4,096 output tokens/request, 1 MiB request bodies, 180-second
coding turns and 120-second approval turns. Native Guardian/request deadlines stay
90 seconds. Failure stops acceptance; no paid retry or model substitution is
planned. Synthetic approval proposals and live Guardian inference are reported
separately. These limits are operational bounds, not a currency cap.

The retained qualification helper has a legacy literal `support_status:
Experimental` field. That field describes neither current candidate admission
nor a fresh support decision. Candidate support scope comes from the reviewed
#75 records above; raw helper evidence is retained without rewriting its labels.

## Regression validation

The frozen source passed native `go test -race ./...`, `go vet ./...`, six release
tests, the focused selection checks, and the installed Codex 0.160.1 synthetic
coding/Guardian fixture. The 16 full Python suites reported 329 tests: 292 passed
and 37 opt-in desktop-engine tests skipped. Those skips provide no installed
desktop-engine or UI qualification. The native Go suite retains its offline Mac
desktop regression coverage.

The exact CI candidate bundle passed four Mac installer lifecycle and two terminal
checks. Every binary's embedded module version, unmodified source revision and
executable architecture matched the freeze; the Mac ARM64 binary also reported
`tofa v0.1.0-rc.15` when executed.

Two setup-only failures are retained separately: an artifact check started before
the download completed, and a metadata audit assumed `go version -m` included
linker flags. Waiting for the download and checking the actual embedded module,
source revision and native version resolved them. Neither began a lifecycle run
or incurred inference. They did not require any candidate changes.

## Mac acceptance result

**Passed**, on macOS 26.7 ARM64 with Codex CLI 0.160.1 and the native Keychain
backend. The [frozen client and runner identities](evidence/rc15-2026-10-08/freeze.json)
are distinct from the candidate binary identity above.

The [full lifecycle report](evidence/rc15-2026-10-08/macos-lifecycle.json) records
all 11 stages passed. Each live phase completed two coding turns in one session,
streamed responses, executed tools, independently checked their output, and
preserved continuation. Native Guardian allow executed the controlled command;
native deny prevented execution. The second phase reused the saved login after
uninstall/reinstall without entering credentials again.

The two phases used **9 + 9 = 18 of 24 permitted upstream requests**, with no
live retry or model substitution. Coding and Guardian inference were live;
approval main-model proposals were synthetic. This is a bounded release sample,
not a new five-model campaign or a desktop UI qualification.

The maintainer explicitly authorized reuse of the saved Mac login in memory to
authenticate only the temporary installation and remove its temporary credential
afterward. The [driver result](evidence/rc15-2026-10-08/macos-driver.json) verifies
the ordinary launcher configuration and saved key were unchanged. All native
Codex, unrelated-state and shell preservation checks passed, and all temporary
installation, configuration, PATH and vault cleanup checks passed. The
[ordinary rc14 installation remains usable](evidence/rc15-2026-10-08/normal-installation.json)
from a fresh shell; rc15 qualification used the isolated installation.
